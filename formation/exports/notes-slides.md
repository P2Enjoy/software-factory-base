# Notes par diapositive

80 diapositives. Les durées se rattachent aux phases du module, sans s’ajouter
au programme de 42 heures. Les deux ouvertures sont comprises dans M1.

## S01 — Coder avec un agent

**Minutage.** Accueil intégré aux 15 premières minutes du module 1.

**Intention.** Poser le résultat du parcours sans présenter l'usine comme point de départ.

**Explication / démonstration.** Le groupe sait déjà obtenir de petites applications. Le cours ajoute les réflexes pour cadrer, comprendre, vérifier et transmettre. Les quinze modules conservent la progression des bases à l'assemblage final.

**Question.** Qu'avez-vous déjà créé avec une IA, et qu'avez-vous réellement vérifié ?

**Réponse attendue.** Un exemple vécu et une incertitude sont suffisants ; il ne s'agit pas d'un concours de niveau.

**Transition.** Présenter le laboratoire et les modalités de travail.

## S02 — Un parcours, deux usages

**Minutage.** Inclus dans l'accueil du module 1, aucun temps ajouté au total.

**Intention.** Rendre l'apprenant autonome dans l'usage des supports.

**Explication / démonstration.** Présenter INSTALLATION, les chapitres, EXERCICES et les corrigés séparés. Vérifier le premier repère Git et les quatre échecs pédagogiques du prototype. Les pauses ne comptent pas dans les 42 heures.

**Question.** Que faire si l'agent ou le réseau est indisponible ?

**Réponse attendue.** Utiliser les supports et le code locaux, avancer manuellement puis reprendre l'assistance ; nommer les preuves non exécutées.

**Transition.** Entrer dans la distinction assistant/agent.

## S03 — De l'assistant à l'agent

**Minutage.** 0–15 min : situation et premières notions ; accueil compris pour M1.

**Intention.** Faire apparaître le problème avant le vocabulaire.

**Explication / démonstration.** Une réponse convaincante n'est pas une action vérifiée. Comparer un conseil copié dans un chat avec une lecture de fichier puis une commande de test visible. Faire distinguer le texte produit de la sortie de l'outil. Ne jamais demander un secret pour démontrer un accès.

**Question.** Un fichier présent sur disque est-il forcément connu du modèle ?

**Réponse attendue.** Non : il doit être chargé ou lu. Les limites de contexte obligent à sélectionner les sources utiles.

**Transition.** Utiliser le schéma pour nommer les relations.
